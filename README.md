Sou estudante de **Análise e Desenvolvimento de Sistemas**, com foco no desenvolvimento de software e interesse em transformar ideias em produtos, sistemas e soluções digitais funcionais.

Minha experiência prática envolve principalmente **desenvolvimento web, sistemas administrativos, bancos de dados, interfaces responsivas e construção de soluções voltadas para problemas reais**.

Atualmente trabalho principalmente com **PHP, JavaScript, MySQL, HTML e CSS**, enquanto amplio meus conhecimentos em Python, engenharia de software, arquitetura de sistemas, automação e inteligência artificial.

Gosto especialmente de projetos que exigem **raciocínio lógico, resolução de problemas, organização de processos e construção de sistemas completos**, desde a interface até a lógica de negócio e o banco de dados.

Meu objetivo não é apenas aprender tecnologias isoladamente, mas desenvolver a capacidade de **analisar problemas, projetar soluções, construir sistemas e transformá-los em produtos utilizáveis**.

> `// I don't just write code. I build systems.`
